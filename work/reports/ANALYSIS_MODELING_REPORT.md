## 0. 赛题理解与子问题拆解

## 1. 数据理解（附件）

- **附件1**（241 行×3 列）：t=0..14400 s（60 s 步长）烘房温度 T_a(℃) 与湿度 C_a(kg/kg，干基)。T_a 从 28 单调爬升至 50 ℃ 附近：t=2640 s 达 45 ℃，t≥10800 s 已稳定（末 30 min 均值 50.013、σ=0.153、末点 50.165）；C_a 从 0.01963 升至 0.0499（末 30 min 均值 0.04999、σ=1.3e-4）。个别相邻点非严格单调（±0.3 ℃ 量级振荡，视为控温波动，不做平滑，插值直接使用）。含义：预热平衡阶段=附件1 覆盖的 0–14400 s（风温爬坡）；恒温干燥阶段=14400 s 后按末端稳定值恒定（T_a∞=50.0 ℃ 取末 30 min 均值，C_a∞=0.0499）。
- **附件2**（145 行×2 列）：t=0..259200 s（1800 s 步长）药材半径 R(cm)：2.000→1.198，单调非增，t=241200 s（67 h）起保持 1.198。t>259200 s 取 1.198（数据末端恒定，外推合理，风险小）。
- **附件3**：result1–4.xlsx 模板。表头行 = 距离 0,0.1,…,2.0（result4 最后一列为“药材表面”）；A 列 = 时间。result1/2 含“温度/水分浓度”两个工作表，行 t=1,2,…；result3/4 单表，行 t=60,120,…（60 s 步长）。

派生指标：Bi_h=hR/k、Bi_m=h_m R/D（判断边界阻力）；时间常数 Fo=Dt/R²。

### 快速验算与递进性检查

- Bi_h(问题1) = hR/k = 25×0.02/0.36 = **1.39** → 集总参数法不可用，必须保留内部梯度（题面要求给 5 个半径的表，与此一致 ✓）。
- 导热时间常数 τ_k=R²/α：问题1 α=k/(ρcp)=0.36/(820×2600)=1.69e-7 m²/s → τ=2367 s≈40 min。30 min 内中心温度显著上升但未满 → 表1 中 T(0,1800)∈(40,50) ℃ 合理。
- Bi_m(问题1)=h_m R/D：C=2.55 时 D=7e-9×e^(−0.349)=4.93e-9 → Bi_m=3.2；Fo_m=Dt/R²=0.022（1800 s）→ 30 min 内水分场几乎不动（表面微降、中心≈2.55）✓ 与“预热平衡以升温为主、失水很少”的物理图景一致。
- 递进性：问题2 换 C/T 依赖物性后，D(C=2.55,T≈301K)=1.70e-9、D(C=0.15,T=323K)=1.50e-8 → 后期干燥加速；问题3 总时长预期在 24–72 h 之间（“一般持续 2–3 天”✓ 量级一致，模型不违背题设先验）。问题4 附录4 的 D 小一个量级（前置系数 4.2e-4 vs 2.4e-3）但路径缩短 (1.198/2)²≈0.36 → t_end4 与 t_end3 接近或略长，收缩应使 t_end4 比“半径不缩”情形更快 → **检验点：若 问题4 反而远慢于 2/0.36≈5.6 倍以外则异常**（因 D4≈D3/6）。
- 恒温段 C_a∞=0.0499 < 0.15：能收敛到要求 ✓；若 C_a∞>0.15 则问题3 无解，反证取值合理。

## 4. 统一模型（各问共用）

**几何与坐标**：圆柱，半径 R=0.02 m（问题1–3 恒定），长 L=0.25 m≫R，忽略轴向变化，一维径向坐标 r∈[0,R]。

**控制方程**（连续、无量纲内积自洽）：

- 能量：ρc(T,C) ∂T/∂t = (1/r) ∂/∂r( k(C) r ∂T/∂r )，其中 ρc 表示 ρ(C)·cp(C)；问题1 中为常数 820×2600。
- 水分（干基）：∂C/∂t = (1/r) ∂/∂r( D(C,T) r ∂C/∂r )。

**边界条件**：r=0：∂T/∂r=∂C/∂r=0（对称）；r=R：k ∂T/∂r = h(T_a(t)−T)，D ∂C/∂r = −h_m(C−C_a(t))（即表面向空气的扩散通量=对流移质通量）。

**初始条件**：T(r,0)=28 ℃，C(r,0)=2.55 kg/kg。

**物性**：

- 问题1：ρ=820、cp=2600、k=0.36、h=25、h_m=8e-7；D=7e-9·exp(−0.89/C)。
- 问题2/3（附录3）：ρ=650+128C；cp=1450+2736·C/(C+1)；k=0.21+0.38·C/(C+1)；D=2.4e-3·exp(−0.45C)·exp(−3850/T[K])。h、h_m 沿用（题面未另给）。
- 问题4（附录4）：ρ=760+90C；cp=1850+2150·C/(C+1)；k=0.12+0.20·C/(C+1)；D=4.2e-4·exp(−0.30C)·exp(−3850/T[K])。

**风况调度**：t≤14400 s：(T_a,C_a)=附件1 线性插值；t>14400 s：恒定为 (50.0 ℃, 0.0499)（末 30 min 均值）。

**问题4 动边界**：r=ξR(t)，ξ∈[0,1] 固定网格（21 节点）。链式法则：∂/∂r=(1/R)∂/∂ξ，(1/r)∂_r(r·a∂_r)=1/(R²ξ)∂_ξ(ξ a ∂_ξ)。方程变为
ρcp ∂T/∂t|ξ = (k/(R²ξ))∂_ξ(ξ ∂_ξT)；∂C/∂t|ξ = (1/(R²ξ))∂_ξ(ξ D ∂_ξC)；
BC：ξ=0 对称；ξ=1：(k/R)∂T/∂ξ=h(T_a−T)，(D/R)∂C/∂ξ=−h_m(C−C_a)。R(t) 由附件2 线性插值（t>259200 s 取 1.198 cm）。忽略收缩骨架功率项与 cp·T·(∂ρ/∂t 修正)（论证：|Ṙ|R/κ_C≈5%，但仅作用于平流自消项）。

**判停（问题3/4）**：t_end = min{t: max_j C_j(t) < 0.15}，线性插值细化到 1 s 级；输出表最后一行取该时刻。

## 5. 数值方法（代码阶段实现规格）

1. 空间：节点控制体有限差分（FVM），dr=R/N，N=20 → 节点恰为 r=0,0.1,…,2.0 cm（表/文件输出零插值误差）。界面扩散系数取调和平均（对 D(C) 强变化稳健），界面面积 A_{j+½}=2π(r_j+dr/2)（问题4 乘 R(t)/R0 比例用 ξ 度量）。
2. 时间：Crank–Nicolson；每步将非线性系数（D(C,T)、k(C)、ρcp(C)）按上一步场冻结并做 2 次定点迭代（用新场重算系数再解一次），消除显式滞后误差。dt 取 0.25 s（问题1/2 输出 1 s 网格；问题3/4 输出 60 s 网格，dt=1 s）。
3. 三对角 Thomas 求解；T、C 两个场各自线性化，耦合仅通过物性。
4. 校验：
   - **守恒**：每步离散水分总量 W(t)=Σ C_j V_j 与 ∫h_m(C_R−C_a)A dt 之差 <0.5%；
   - **网格收敛**：N=20 与 N=40、dt 减半 → 表中值最大偏差（预期 <5e-5）；
   - **物理单调**：C 衰减单调、T 上凸趋衡；中心 C ≥ 表面 C、中心 T 滞后。
5. 稳定性：CN 无条件稳定（线性化）；调和平均系数有正性保证。

## 7. 灵敏度分析与检验方案（对应论文第八、九章）

1. 数值可信性：网格/步长收敛、守恒闭合。
2. 模型假设检验：端面换热修正、恒温取值、D 下限截断。
3. 参数灵敏度：局部 ±20%（单因素，龙卷风图）→ 找主导参数（预期 h_m 与 D 前置系数）。
4. 合理性校核：t_end 与“2–3 天”先验一致；问题4 收缩使干燥加快/略变的物理解释。
