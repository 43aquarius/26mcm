# 赛题分析与建模报告

## 1. 问题重述

### 背景

中药材烘干是决定成品品质的关键工序，采用热风烘干方式，包括预热平衡和恒温干燥两个阶段。传统试验优化模式存在成本高、周期长等问题，需要借助数理分析与数值仿真方法得到干燥规律。

### 已知条件

**药材几何参数：**
- 圆柱形，长度 L = 25 cm，半径 R = 2 cm
- 初始温度 T₀ = 28°C
- 初始水分浓度 C₀ = 2.55 kg/kg（干基含水率）

**烘房条件（附件 1）：**
- 时间序列：0~14400s（240 分钟），间隔 60s
- 温度范围：28°C ~ 约 60°C
- 水分浓度范围：0.01963 ~ 约 0.06 kg/kg

**物性参数（附录 2-4）：**
- 问题 1：恒定物性参数
- 问题 2-3：物性参数随 C,T 变化
- 问题 4：考虑尺寸收缩，R(t) 由附件 2 给出

### 四个子问题

| 问题 | 任务 | 输出要求 |
|------|------|----------|

## 2. 问题分析

### 2.1 物理过程分析

中药材烘干过程涉及两个耦合的物理过程：

**1. 热量传递过程**
- 外部：热风通过对流换热将热量传递给药材表面
- 内部：热量通过热传导从表面向中心传递
- 控制方程：非稳态热传导方程（圆柱坐标系）

**2. 质量传递过程**
- 外部：药材表面水分通过对流传质进入热风
- 内部：水分通过扩散从内部向表面迁移
- 控制方程：非稳态扩散方程（Fick 第二定律，圆柱坐标系）

**3. 耦合机制**
- 温度影响扩散系数 D(T,C)
- 水分浓度影响物性参数ρ(C), cp(C), k(C)
- 蒸发潜热影响能量平衡（边界条件）

### 2.2 数学模型类型

本题属于**偏微分方程初边值问题**：
- 空间域：圆柱体径向一维（因长径比大，忽略轴向变化）
- 时间域：非稳态瞬态过程
- 方程类型：抛物型偏微分方程组
- 边界条件：第三类边界条件（对流换热/传质）

### 2.3 求解策略

采用**有限差分法**进行数值求解：
1. 空间离散：径向网格划分
2. 时间推进：隐式格式或 Crank-Nicolson 格式
3. 耦合处理：交替迭代或联立求解
4. 边界处理：能量平衡和质量平衡推导离散边界条件

## 3. 基本假设

### 3.1 几何简化假设

**假设 H1：一维径向模型**
- 理由：药材长径比 L/(2R) = 25/4 = 6.25 > 5，可忽略端部效应
- 影响：将三维问题简化为一维径向问题，大幅降低计算复杂度
- 验证：可在论文中说明此假设的适用范围

**假设 H2：圆柱对称性**
- 理由：药材形状规则，烘干条件均匀
- 影响：温度和水份浓度仅与径向位置 r 和时间 t 有关
- 数学表达：T = T(r,t), C = C(r,t)

### 3.2 物理过程假设

**假设 H3：忽略内部热源**
- 理由：烘干过程无化学反应放热
- 影响：能量方程无源项

**假设 H4：忽略重力影响**
- 理由：水分扩散主要由浓度梯度驱动
- 影响：扩散方程无重力项

**假设 H5：表面蒸发发生在边界层**
- 理由：对流传质模型的标准假设
- 影响：边界条件采用对流传质公式

**假设 H6：物性参数在问题 1 中恒定**
- 理由：题目明确要求使用附录 2 的恒定参数
- 影响：简化问题 1 的计算

**假设 H7：局部热平衡**
- 理由：多孔介质内部温度快速平衡
- 影响：可用单一温度场描述

### 3.3 数值计算假设

**假设 H8：网格独立性**
- 理由：Δr = 0.1 cm 满足精度要求
- 验证：可通过网格加密验证

**假设 H9：时间步长稳定性**
- 理由：采用隐式格式无条件稳定
- 验证：可通过步长减半验证收敛性

## 5. 数学模型

### 5.1 控制方程

#### 5.1.1 能量方程（圆柱坐标）

$$\rho c_p \frac{\partial T}{\partial t} = k \left[ \frac{1}{r} \frac{\partial}{\partial r} \left( r \frac{\partial T}{\partial r} \right) \right]$$

展开形式：
$$\frac{\partial T}{\partial t} = \alpha \left( \frac{\partial^2 T}{\partial r^2} + \frac{1}{r} \frac{\partial T}{\partial r} \right)$$

其中α = k/(ρcp) 为热扩散系数 (m²/s)。

#### 5.1.2 扩散方程（圆柱坐标）

$$\frac{\partial C}{\partial t} = \frac{1}{r} \frac{\partial}{\partial r} \left( r D \frac{\partial C}{\partial r} \right)$$

当 D 为常数时：
$$\frac{\partial C}{\partial t} = D \left( \frac{\partial^2 C}{\partial r^2} + \frac{1}{r} \frac{\partial C}{\partial r} \right)$$

当 D = D(C,T) 时：
$$\frac{\partial C}{\partial t} = D \frac{\partial^2 C}{\partial r^2} + \left( \frac{D}{r} + \frac{\partial D}{\partial r} \right) \frac{\partial C}{\partial r}$$

### 5.2 初始条件

$$T(r, 0) = T_0 = 28°C, \quad 0 \leq r \leq R$$
$$C(r, 0) = C_0 = 2.55 \text{ kg/kg}, \quad 0 \leq r \leq R$$

### 5.3 边界条件

#### 5.3.1 中心对称条件 (r = 0)

由对称性：
$$\frac{\partial T}{\partial r}\bigg|_{r=0} = 0$$
$$\frac{\partial C}{\partial r}\bigg|_{r=0} = 0$$

#### 5.3.2 表面对流边界 (r = R)

**能量平衡：**
传入表面的热通量 = 内部导热通量 + 蒸发潜热

$$h[T_\infty(t) - T(R,t)] = -k \frac{\partial T}{\partial r}\bigg|_{r=R} + h_m [C_s - C_\infty(t)] \cdot L_v \cdot \rho$$

其中：
- Lv 为水的汽化潜热，约 2.26×10⁶ J/kg
- Cs 为表面平衡水分浓度（需根据吸附等温线确定）

**简化处理：** 若忽略蒸发潜热影响（或认为已包含在对流换热系数中）：
$$h[T_\infty(t) - T(R,t)] = -k \frac{\partial T}{\partial r}\bigg|_{r=R}$$

**质量平衡：**
表面扩散通量 = 对流传质通量

$$-D \frac{\partial C}{\partial r}\bigg|_{r=R} = h_m [C(R,t) - C_\infty(t)]$$

## 6. 数值解法

### 6.1 空间离散

采用有限差分法，将径向区域 [0, R] 划分为 N 个网格：

$$r_i = i \cdot \Delta r, \quad i = 0, 1, 2, ..., N$$
$$\Delta r = R/N$$

根据题目要求，输出位置为 0, 0.5, 1, 1.5, 2 cm，完整结果间隔 0.1 cm，因此：
- Δr = 0.1 cm = 0.001 m
- N = R/Δr = 2/0.1 = 20 个区间

### 6.2 时间离散

时间步长Δt，根据稳定性要求选择：
- 显式格式：需满足 CFL 条件 Δt ≤ Δr²/(4α)
- 隐式格式：无条件稳定，推荐使用

### 6.3 离散格式

#### 6.3.1 内部节点 (i = 1, 2, ..., N-1)

**热传导方程（全隐式）：**

$$\frac{T_i^{n+1} - T_i^n}{\Delta t} = \alpha \left[ \frac{T_{i+1}^{n+1} - 2T_i^{n+1} + T_{i-1}^{n+1}}{\Delta r^2} + \frac{1}{r_i} \frac{T_{i+1}^{n+1} - T_{i-1}^{n+1}}{2\Delta r} \right]$$

整理得：
$$-\beta_t \left(1 - \frac{\Delta r}{2r_i}\right) T_{i-1}^{n+1} + (1 + 2\beta_t) T_i^{n+1} - \beta_t \left(1 + \frac{\Delta r}{2r_i}\right) T_{i+1}^{n+1} = T_i^n$$

其中βt = αΔt/Δr²。

**扩散方程（全隐式）：**

$$\frac{C_i^{n+1} - C_i^n}{\Delta t} = D \left[ \frac{C_{i+1}^{n+1} - 2C_i^{n+1} + C_{i-1}^{n+1}}{\Delta r^2} + \frac{1}{r_i} \frac{C_{i+1}^{n+1} - C_{i-1}^{n+1}}{2\Delta r} \right]$$

整理得类似形式。

#### 6.3.2 中心节点 (i = 0)

利用 L'Hospital 法则处理 1/r 奇点：

$$\lim_{r \to 0} \frac{1}{r} \frac{\partial T}{\partial r} = \frac{\partial^2 T}{\partial r^2}\bigg|_{r=0}$$

因此中心点方程：
$$\frac{T_0^{n+1} - T_0^n}{\Delta t} = 2\alpha \frac{T_1^{n+1} - T_0^{n+1}}{\Delta r^2}$$

同理对于 C。

#### 6.3.3 表面节点 (i = N)

**能量边界（第三类边界）：**

$$h(T_\infty - T_N) = -k \frac{T_N - T_{N-1}}{\Delta r}$$

整理得：
$$T_N = \frac{k T_{N-1} + h \Delta r T_\infty}{k + h \Delta r}$$

**质量边界（第三类边界）：**

$$-D \frac{C_N - C_{N-1}}{\Delta r} = h_m (C_N - C_\infty)$$

整理得：
$$C_N = \frac{D C_{N-1} + h_m \Delta r C_\infty}{D + h_m \Delta r}$$

### 6.4 算法流程

```
For each time step n:
    1. 读取当前烘房条件 T∞(t), C∞(t)
    2. 更新物性参数（问题 2-4）
    3. 求解温度场 T^(n+1)
       - 组装三对角矩阵
       - 调用 TDMA 求解器
    4. 求解水分场 C^(n+1)
       - 更新扩散系数 D(C,T)
       - 组装三对角矩阵
       - 调用 TDMA 求解器
    5. 检查收敛性（问题 3 终止条件）
    6. 保存结果
```

### 7.2 问题 2：完整烘干过程

**特点：**
- 时间范围：0 ~ 3h+（直到接近稳态）
- 物性参数随 C,T 变化（附录 3）

**输出：**

### 7.3 问题 3：烘干时间确定

**终止条件：**
- 药材各处水分浓度 ≤ 0.15 kg/kg
- 即 max(C(r,t)) ≤ 0.15

**求解策略：**
- 延续问题 2 的模型
- 持续计算直到满足终止条件
- 记录烘干结束时间

**输出：**
- 表 5：每隔 6h 的水分浓度分布
- result3.xlsx：完整时空数据
- 烘干总时长

### 7.4 问题 4：考虑尺寸收缩

**特点：**
- 半径 R(t) 随时间变化（附件 2）
- 移动边界问题
- 物性参数用附录 4 公式

**处理方法：**
- 方案 A：动网格法，网格随 R(t) 伸缩
- 方案 B：坐标变换，将物理域映射到固定计算域
- 方案 C：阶梯近似，每段时间内 R 视为常数

**推荐方案 B：** 引入无量纲坐标ξ = r/R(t)，则：
$$\frac{\partial C}{\partial t} = \frac{1}{R^2} \frac{\partial}{\partial \xi} \left( D \frac{\partial C}{\partial \xi} \right) + \frac{\xi \dot{R}}{R} \frac{\partial C}{\partial \xi}$$

**物性公式（附录 4）：**
- ρ = 760 + 90C kg/m³
- cp = 1850 + 2150·C/(C+1) J/(kg·K)
- k = 0.12 + 0.20·C/(C+1) W/(m·K)
- D = 4.2×10⁻⁴·exp(-0.30/C)·exp(-3850/T) m²/s

**输出：**
- 表 6：考虑收缩的水分浓度分布
- result4.xlsx：完整时空数据
- 考虑收缩的烘干时长
